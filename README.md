# MochicakeWaterSort

A relaxing yet challenging puzzle game where you sort colored liquids into bottles!

## About the Game

**MochicakeWaterSort** is a water sorting puzzle game where your goal is to organize colored liquids so that each bottle contains only one color. It's an addictive puzzle experience that gets progressively harder as you advance through levels.

## How to Play

- **Objective**: Sort all bottles so each contains only a single color
- **Pour Water**: Click on bottles to pour water from one bottle to another
- **Rules**:
  - You can only pour if the top colors match or the destination is empty
  - Each bottle holds 4 units of liquid
  - The bottle can't be full or already complete

## Features

 **Infinite Gameplay** - Procedurally generated levels that increase in difficulty
 **Star Rating System** - Earn up to 3 stars based on your performance
 **Progressive Difficulty** - Start with 4 bottles and work up to 12
 **Auto-Save** - Your progress is saved automatically

## Bonus Objectives

Complete levels with perfect moves for stars:
- Don't use the Undo feature
- Don't use the Extra Bottle feature
